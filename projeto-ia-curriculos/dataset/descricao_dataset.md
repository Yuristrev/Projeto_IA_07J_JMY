# Dataset de Currículos

Este dataset foi desenvolvido pelo próprio grupo para fins acadêmicos e contém 20 currículos fictícios utilizados no treinamento e avaliação do modelo de classificação de candidatos.

As vagas utilizadas no projeto foram:

* Analista de Recrutamento e Seleção
* Analista de Dados Júnior

Todos os dados foram anonimizados e criados de forma fictícia, evitando o uso de informações pessoais reais.

## Atributos do Dataset

* id_candidato
* texto_curriculo
* experiencia_anos
* formacao
* habilidades
* vaga
* classificacao

## Objetivo do Dataset

O objetivo do dataset é permitir a aplicação de técnicas de Processamento de Linguagem Natural (PLN) e Machine Learning para classificação automática de currículos como “apto” ou “não apto” para determinadas vagas.

## Técnicas Utilizadas no Projeto

Durante o desenvolvimento do projeto foram utilizadas técnicas de limpeza e pré-processamento textual, transformação de texto utilizando TF-IDF, treinamento com Regressão Logística, análise exploratória dos dados e avaliação do modelo utilizando métricas como acurácia e precisão.
